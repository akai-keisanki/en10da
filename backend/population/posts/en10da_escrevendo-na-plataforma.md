# Linguagem de marcação

Uma linguagem de marcação permite usar caractéres disponíveis na maioria dos teclados de computador para a formatação ou organização visual de texto.

A plataforma utiliza a linguagem [Markdown](https://pt.wikipedia.org/wiki/Markdown) e a linguagem [\KaTeX](https://katex.org/) para a formatação dos posts, assim como este.
